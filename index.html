Chrona

Version 1.0

Chrona is a lightweight time tracking application built with HTML5 by PrinTech Solutions. Designed for simplicity and reliability, Chrona helps you log work sessions, monitor productivity, and generate clear reports.

Key Features:

  • ✅ Start and stop timers with one click
  • ✅ Track employee hours by week
  • ✅ Export logs for easy reporting
  • ✅ Secure PIN-based authentication
  • ✅ Works offline - no internet required
